# Google Photos Downloader

تطبيق Android بسيط لاستخراج الصور والفيديوهات من ملفات Google Takeout ZIP وحفظها مباشرة في الهاتف.

## لماذا Takeout؟

Google Photos لا يوفر حاليًا لتطبيقات جديدة صلاحية عامة لتنزيل كامل مكتبة المستخدم عبر Library API. لذلك النسخة الأولى تعتمد على أرشيف Google Takeout بدل طلب صلاحيات حساسة أو محاولة تجاوز قيود Google.

## الاستخدام

1. أنشئ Google Takeout واختر Google Photos.
2. نزّل ملف ZIP إلى هاتف Android.
3. افتح التطبيق واضغط **اختيار ZIP**.
4. اختر الأرشيف ثم **بدء الاستخراج**.
5. الملفات تحفظ في:

`Pictures/GooglePhotosDownloader`

## النسخة الحالية

- JPG / JPEG / PNG / WEBP / HEIC / HEIF / GIF / BMP
- MP4 / M4V / MOV / AVI / MKV / WEBM
- يعمل مباشرة من URI للملف بدون الحاجة إلى نسخ ZIP كاملًا إلى ذاكرة التطبيق.
- يستخدم MediaStore حتى تظهر الملفات في تطبيقات الصور والملفات الحديثة.

> هذه هي النسخة الأولى (MVP). في الخطوة التالية نضيف استكمالًا ذكيًا، منع التكرار، تنظيمًا أفضل، وواجهة تقدم أدق.
